# 信息架构与关键流程

## 小程序导航

底部导航建议四项：

1. 日历：月历、今日排班摘要；
2. 周视图：未来七天班次和天气；
3. 提醒：提醒设置与消息摘要；
4. 我的：账号、班次管理、改班记录、分享设置。

从日历日期进入“排班详情”；详情页提供“临时改班”和“分享班表”。

## APP 导航

底部导航建议：

1. 首页；
2. 班表；
3. 中央新增按钮；
4. 消息；
5. 我的。

首页聚合今日班次、下一班次、快捷操作与天气简报。班表页包含月历、周视图和统计。APP 可承载更完整消息中心、离线缓存和系统推送。

## 流程 A：首次使用

登录 → 选择个人使用或加入组织 → 设置默认城市与提醒 → 创建或选择班次模板 → 选择排班方式 → 预览生成结果 → 保存 → 首页显示今日/下一班次。

## 流程 B：循环排班

进入班表 → 新建排班 → 选择“循环” → 设置起始日期 → 添加序列，例如早、早、晚、晚、休、休 → 选择结束日期或长期 → 预览 → 冲突检查 → 生成实例。

## 流程 C：临时改班

排班详情 → 临时改班 → 查看原班次 → 选择模板或自定义时间 → 设置仅当天 → 填写原因 → 提交。

- 个人模式：保存实例新版本 → 通知与天气任务重排。
- 组织审批模式：创建申请 → 主管审批 → 通过后修改实例 → 通知双方。

## 流程 D：组织排班

选择日期范围 → 筛选部门/员工 → 选择班次模板 → 批量应用 → 冲突分析 → 确认覆盖策略 → 提交 → 异步通知与统计刷新。

## 流程 E：分享

选择分享入口 → 选择范围 → 选择海报模板 → 设置隐私项 → 预览 → 生成快照与图片 → 保存/系统分享/创建链接 → 可在分享记录中撤销链接。

## 流程 F：天气提醒

排班实例创建或变更 → 确定地点坐标 → 加入天气刷新计划 → 获取预报并缓存 → 根据提醒时间和异常规则生成通知任务 → 去重后发送 → 记录送达结果。
