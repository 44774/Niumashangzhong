# 用户故事与验收示例

## 个人用户

### 查看今天上什么班

作为倒班用户，我希望打开应用后立即看到今天的班次和上班时间，以免查看错日期。

验收：

- 首页首屏显示今日班次；
- 无排班时显示明确空状态并提供“添加排班”；
- 跨午夜班次显示完整日期与时间；
- 进行中班次显示状态；
- 天气加载失败不影响班次卡片。

### 查看未来工作日天气

作为用户，我希望周视图中的每个工作日都显示天气摘要，以便准备出行。

验收：

- 有地点时按班次地点查询；
- 无地点时使用默认城市；
- 天气过期时后台刷新，页面先显示缓存；
- 超出供应商预报范围时显示“暂不可用”。

### 临时修改今天班次

作为用户，我希望仅修改今天的班次，而不破坏后续循环。

验收：

- 页面明确显示原班次与新班次；
- 默认影响范围为“仅今天”；
- 保存后产生变更记录；
- 循环规则保持不变；
- 有审批策略时状态为待审批，原排班在审批前仍有效或按组织策略处理。

### 分享班表

作为用户，我希望把下周班表分享给家人。

验收：

- 可选择日、周、月范围；
- 可隐藏地点和备注；
- 海报包含日期、班次与图例；
- 图片生成失败可重试；
- 分享快照与生成时数据一致。

## 排班管理员

### 批量安排团队班次

作为排班员，我希望给一个部门批量安排下周早班。

验收：

- 可选择日期范围、部门、人员与班次；
- 提交前显示预计影响人数与冲突；
- 可跳过冲突或覆盖并填写原因；
- 操作写入审计日志；
- 员工收到变更通知。

### 审批改班

作为主管，我希望看到员工申请的原班次、新班次和原因后进行审批。

验收：

- 待审批列表按提交时间排序；
- 通过时原排班产生新版本；
- 驳回必须填写或可配置填写意见；
- 重复点击不会重复执行；
- 员工收到结果通知。

### 发现排班冲突

作为管理员，我希望系统指出同一员工时间重叠或休息不足。

验收：

- 同时段重叠标记为严重冲突；
- 跨午夜计算正确；
- 休息间隔低于组织阈值标记为警告；
- 管理员可查看原因并有权限地覆盖；
- 覆盖原因进入审计日志。
