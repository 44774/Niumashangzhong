# 阶段 4：天气、通知、分享与导入导出

## 目标

- 建立天气 Provider 接口和 mock Provider；
- 缓存未来工作日天气并显示异常天气；
- 建立通知偏好、调度、去重、重试和回执；
- 实现小程序订阅消息适配、APP 推送适配和本地开发通道；
- 实现分享快照、海报渲染、保存和分享链接；
- 实现 CSV 导入与错误报告；
- 实现排班导出；
- 后台增加任务状态和失败重试能力。

## 安全

- Provider 密钥不进入前端；
- 分享 token 保存哈希；
- 海报模板转义输入；
- CSV 防公式注入；
- 文件私有存储并限时下载。

## 降级

外部服务全部可关闭或 mock，核心排班仍完整可用。
