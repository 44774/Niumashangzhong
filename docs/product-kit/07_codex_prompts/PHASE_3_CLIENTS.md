# 阶段 3：小程序、APP 与管理后台 UI

## 目标

根据效果图和 `02_ui` 实现真实页面：

### 小程序/APP

- 登录与工作空间；
- 首页/我的班表；
- 月历、周视图、排班详情；
- 创建与临时改班；
- 班次模板管理；
- 提醒设置；
- 消息中心基础；
- 分享预览基础；
- 个人设置。

### 管理后台

- 登录；
- 仪表盘；
- 排班日历与员工排班表；
- 员工、部门、班次模板；
- 改班审批；
- 角色和审计基础；
- 响应式和权限状态。

## UI 要求

- 设计令牌集中使用，不散落硬编码颜色；
- 页面不是静态假数据，真实调用 API；
- 开发模式可使用 seed 数据；
- 所有加载、空、错误、离线和无权限状态齐全；
- 使用效果图的布局方向，但处理安全区和不同屏幕；
- 为关键组件增加视觉或组件测试。
