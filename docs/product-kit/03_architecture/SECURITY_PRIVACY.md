# 安全与隐私设计

## 身份认证

- 短期访问令牌 + 可撤销刷新会话，或安全服务端会话；
- 管理员账号建议支持二次验证；
- 验证码限流，防止枚举账号；
- 密码使用现代自适应哈希；
- 设备和会话可查询、撤销；
- 登录、改密、绑定账号等敏感操作写入安全日志。

## 授权

- 每个组织资源查询都必须从当前登录成员关系推导组织范围；
- 不信任客户端提交的 `organization_id`；
- 使用 RBAC + 资源范围，例如部门主管只能管理指定部门；
- 后台路由隐藏不等于授权，服务端必须验证每个动作。

## 数据保护

- TLS；
- 密钥只存秘密管理系统，不提交仓库；
- 对象存储默认私有，下载使用短期签名 URL；
- 日志脱敏手机号、邮箱、token、地址和经纬度；
- 分享 token 使用高熵随机值，数据库保存哈希；
- 导出文件带过期时间，下载记录审计。

## 常见风险

- IDOR：通过组织作用域查询防止越权；
- 重放：写接口支持幂等键和时间限制；
- CSV 注入：导出时转义以 `= + - @` 开头的单元格；
- 批量导入：限制大小、类型、行数，异步解析；
- 海报 HTML 渲染：模板和用户输入严格转义；
- SSRF：天气 Provider URL 不允许由普通管理员自由输入；
- 推送滥用：消息模板与频率限制；
- 时间边界：DST、跨午夜和时区必须有测试。

## 隐私设置

- 申请定位权限前解释用途；
- 天气可使用手动城市，不强制精确定位；
- 分享前展示将包含的字段；
- 支持账号注销、数据导出和撤销分享；
- 管理后台展示个人信息遵循最小必要原则。
