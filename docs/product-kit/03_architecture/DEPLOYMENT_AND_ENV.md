# 部署与环境

## 环境

- local：本地开发，所有外部服务可 mock；
- test：自动化测试，隔离数据库；
- staging：接近生产，用测试账号与供应商沙箱；
- production：生产。

## 必要配置分类

- 数据库与 Redis；
- 访问令牌/会话密钥；
- 对象存储；
- 天气 Provider；
- 短信/邮件/推送/小程序订阅消息；
- 海报渲染服务；
- 日志、监控和错误上报；
- 公网域名、回调地址、CORS 白名单。

`.env.example` 只包含变量名和说明，不得包含真实密钥。

## 部署拓扑

反向代理/CDN → API 与 Admin 静态资源 → API 实例 → PostgreSQL/Redis/对象存储；Worker 独立扩缩容。管理后台与 API 使用不同子域或清晰路径，后台接口可增加网络策略。

## 发布流程

1. lint、类型检查、单元测试；
2. 数据库迁移 dry-run；
3. 构建所有应用；
4. 集成与端到端测试；
5. 生成版本与变更记录；
6. 先部署 API/Worker 兼容版本；
7. 再发布后台与客户端；
8. 监控错误率和队列；
9. 支持快速回滚。

数据库迁移必须向前兼容滚动发布，删除字段采用“先停止写入、再迁移、最后删除”的多阶段策略。
