# 管理与运营规则

## 导入

- 提供标准 CSV 模板；
- 必填：员工标识、业务日期、班次；
- 可选：地点、备注；
- 首先上传并解析预览；
- 展示总行数、有效、警告、错误和冲突；
- 提交后生成异步任务；
- 错误报告可下载；
- 同一文件重复提交通过文件哈希和幂等键提示。

## 导出

按权限过滤字段。常规导出包含员工、日期、班次、时间、地点名称、状态。内部备注和个人信息需要额外权限。防止 CSV 公式注入。

## 任务运营

后台应展示：任务类型、发起人、进度、成功/失败数量、错误摘要、创建/完成时间、重试按钮。重试必须重用幂等策略。

## 异常处理

- 天气 Provider 故障：自动切换可选备用或展示缓存；
- 通知渠道故障：保留站内消息并告警；
- 海报失败：允许重试，不影响分享快照；
- 导入部分失败：成功项可提交，失败项单独报告，由管理员选择全有或全无模式。
