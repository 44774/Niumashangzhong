# 天气、通知与分享方案

## 天气 Provider 接口

统一方法：地点解析、当前天气、逐日预报、预警。Provider 返回规范化模型和原始数据摘要。实现超时、熔断、重试、缓存和配额监控。

天气刷新建议：

- 创建/修改排班时异步预热；
- 未来 3 天更频繁刷新；
- 更远日期低频刷新；
- 到达预报范围外不重复请求；
- 页面手动刷新限流。

## 通知调度

排班实例变更后发布领域事件。通知服务根据用户偏好生成任务。任务在发送前再次读取实例版本，版本不一致则取消并重建。

渠道适配：

- 小程序订阅消息；
- APP 推送；
- APP 本地通知；
- 站内消息；
- 可选短信/邮件，仅用于组织明确配置的场景。

## 分享海报

后端创建分享快照；Worker 使用受控模板渲染 1080 px 宽图片并上传私有对象存储；客户端获取短期下载地址。模板数据必须经过白名单映射，不直接把数据库对象传给模板。

## 分享链接

- 生成随机 token；
- 数据库存 token 哈希；
- 默认 7 天过期；
- 可撤销；
- 访问页面不要求登录，但只展示快照允许字段；
- 可配置禁止搜索引擎索引；
- 访问统计仅记录匿名计数和时间桶。
