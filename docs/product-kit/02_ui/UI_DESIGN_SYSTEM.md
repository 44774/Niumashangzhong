# UI 设计规范

## 1. 视觉定位

关键词：清晰、可靠、轻量、友好、现代。视觉基调来自效果图中的蓝色、青色和绿色，主要信息使用白色卡片承载，班次使用稳定的语义色。

## 2. Logo 与品牌

- 主图标：蓝绿渐变圆角方形、白色日历和勾选。
- 图标周围至少保留图标宽度 12.5% 的安全空间。
- 小于 24 px 时使用简化 SVG 或 PNG，不显示横向文字。
- 不允许拉伸、旋转、改变渐变方向、叠加复杂纹理或把图标置于低对比背景。
- 单色场景使用 `work-calendar-icon-monochrome.svg`。

## 3. 色彩

### 品牌色

- 主蓝 `#1F6FEB`：主按钮、选中状态、链接、导航高亮。
- 青色 `#00C4CF`：渐变过渡、天气与信息提示。
- 绿色 `#10B981`：早班、成功、进行中。
- 深蓝 `#0F2B4D`：标题和品牌字。

### 班次色

- 早班：绿色 `#10B981`；
- 晚班：蓝色 `#2F80ED`；
- 夜班：紫色 `#7C3AED`；
- 休息：灰色 `#94A3B8`；
- 请假/异常：橙色 `#F59E0B`；
- 错误/冲突：红色 `#EF4444`。

颜色不是唯一编码。标签中必须展示班次文字，图表需要图例或纹理/标记。

## 4. 字体与层级

优先使用系统中文无衬线字体，不随包分发字体文件。

- 页面大标题：28/36，700；
- 模块标题：18/26，600；
- 卡片标题：16/24，600；
- 正文：14/21，400；
- 辅助文字：12/18，400；
- 时间数字可使用 22–36，600–700；
- 表格正文：13–14。

移动端避免大段居中正文。金额或时长等数字使用等宽数字特性，但不强制等宽字体。

## 5. 布局与间距

采用 4 px 基础网格。移动端页面左右安全边距 16 px，紧凑设备可降至 12 px。卡片内边距通常 16 px，重要卡片 20–24 px。

- 同组元素：8–12 px；
- 卡片间：12–16 px；
- 模块间：24–32 px；
- 后台内容最大宽度 1440 px；
- 后台侧栏 224 px，可折叠至图标模式。

## 6. 圆角与阴影

- 小标签：6 px；
- 输入框、按钮：10 px；
- 普通卡片：14 px；
- 大型天气/分享卡：18–24 px；
- 胶囊标签：999 px。

阴影要克制。列表内卡片可仅使用边框，悬浮层和主视觉卡片才使用中等阴影。

## 7. 图标

- 使用统一线性图标集，默认 20–24 px，描边 1.75–2 px；
- 选中导航可用填充图标；
- 天气图标允许彩色；
- 图标按钮必须有可访问名称；
- 不混用明显不同的图标风格。

## 8. 动效

- 点击反馈 120 ms；
- 卡片、抽屉、弹窗 200–320 ms；
- 使用位移与透明度，避免大面积弹跳；
- 遵守系统“减少动态效果”设置；
- 日历切月应保持头部稳定，只过渡内容。

## 9. 状态设计

每个数据页必须包含：加载骨架、空状态、错误状态、离线状态、无权限状态和成功反馈。

- 空班表：说明没有排班并提供创建入口；
- 天气错误：局部错误，不占满页面；
- 保存中：主按钮禁用并展示进度；
- 冲突：红色摘要 + 可展开详情，不能只弹一次提示；
- 待审批：黄色状态标签，并保留原排班说明。

## 10. 响应式

- 小程序与 APP 按 375 px 设计基准，适配 320–430 px 常见宽度；
- 使用安全区变量处理刘海与底部手势区域；
- 后台在 ≥1200 px 使用三栏仪表盘，在 768–1199 px 收敛为两栏；
- 表格在窄屏支持固定关键列、横向滚动或卡片模式；
- 分享海报采用固定导出画布，但预览按容器缩放。
