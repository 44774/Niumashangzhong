# 可访问性与内容规范

## 可访问性

- 正文文本与背景对比度至少达到常规可读标准；
- 触控目标最小 44×44 px；
- 键盘焦点可见，后台全部核心流程可键盘完成；
- 表单错误以文字说明，不只使用红色；
- 班次区分同时依赖文字、颜色和必要图标；
- 动画支持减少动态效果；
- 图片分享预览提供文本摘要；
- 图表提供表格或可访问描述；
- 日期读屏文本使用完整格式，例如“2026 年 8 月 3 日，星期一，早班 09:00 至 17:30”。

## 中文内容风格

- 直接、友好、避免技术术语；
- 按钮使用动作动词：“保存修改”“提交审批”“生成海报”；
- 不使用含糊按钮：“确定”仅用于上下文非常明确的简单确认；
- 时间统一 `HH:mm`；
- 日期按场景使用 `M月D日 周X` 或完整日期；
- 跨午夜明确写“次日 07:00”；
- 危险操作说明后果和影响范围。

## 示例文案

- 空班表：“这个月还没有排班。添加一个班次，让工作安排一目了然。”
- 天气不可用：“暂时无法获取天气，不影响查看班表。”
- 离线：“当前为离线数据，上次同步于 08:30。”
- 冲突：“该时段与 8 月 3 日夜班重叠，请调整时间或填写覆盖原因。”
- 临时改班成功：“8 月 3 日已改为晚班，其他日期不受影响。”
- 待审批：“申请已提交。审批通过前，原班次仍然有效。”
