# 资源使用说明

## 效果图

三张效果图用于视觉方向、页面结构和产品沟通。开发时请参考其：

- 蓝绿品牌色；
- 白色圆角卡片；
- 月历班次标签；
- 今日班次与天气组合；
- 管理后台信息密度与三栏布局。

不要从效果图中裁切按钮或文字作为真实界面资源。所有界面必须使用代码和矢量图标实现。

## Logo 文件选择

- APP 商店与启动图标：`work-calendar-icon-1024.png`；
- Android/PWA：`android-chrome-*`；
- iOS Web：`apple-touch-icon.png`；
- 浏览器：`favicon.ico`；
- 后台顶部品牌：`work-calendar-logo-horizontal.svg`；
- 单色印刷/深色背景：`work-calendar-icon-monochrome.svg`。

## 导出注意

平台可能要求不同圆角或安全区。不要再次在平台图标外层增加圆角白框；应从 1024 原图按平台规范生成。
