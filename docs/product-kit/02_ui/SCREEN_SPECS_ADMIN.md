# 管理后台页面规格

## 仪表盘

顶部指标：员工总数、今日值班、早班、晚班、夜班、休息和今日天气。

主体：

- 排班日历；
- 今日值班详情；
- 快捷操作；
- 待办事项；
- 员工排班表；
- 改班审批；
- 班次分布与趋势。

指标卡必须可点击进入对应筛选结果。趋势图要提供数据表或导出入口。

## 排班管理

视图：月、周、日、员工表。

操作：新建单项、批量排班、拖拽调整、复制上周、应用模板、导入、导出、发布通知。

提交前显示：影响人数、创建/覆盖数量、冲突数量、预计通知数量。大量操作进入异步任务并显示进度。

## 员工管理

列：姓名、部门、角色、状态、默认地点、加入时间、当前/下一班次。支持邀请、批量导入、停用、移动部门和重置邀请。

## 班次管理

班次模板卡或表格显示名称、简称、颜色、时间、跨日、休息分钟、使用人数和状态。停用模板不能影响历史排班。

## 改班审批

标签页：待审批、已通过、已驳回、已撤回。详情抽屉展示排班前后对比、原因、冲突、申请与审批时间线。

## 天气联动

显示 Provider 状态、缓存命中率、最近同步、失败任务、异常天气预警、地点覆盖。密钥必须只显示掩码。

## 分享设置

配置组织 Logo、品牌色、海报模板、默认隐私项、链接有效期和水印。预览需要使用示例数据。

## 统计分析

筛选日期、部门、班次、成员。指标包括排班人次、预计工时、出勤/请假（若接入）、改班、加班、覆盖率和冲突。所有图表说明口径和时区。

## 权限与审计

角色权限使用模块-动作矩阵。审计日志支持按操作者、动作、资源、日期和请求 ID 查询，只读展示前后差异摘要。
