# APP 页面规格

## 首页

首屏顺序：问候与通知入口 → 今日班次主卡 → 下一班次 → 快捷操作 → 天气简报。

今日卡主视觉使用绿色或当前班次色，但背景和文字必须达到可读对比度。主卡展示状态、时间、地点和天气。

快捷操作：班表、临时改班、分享班表、消息中心。中央新增按钮用于创建单日或循环排班。

## 班表

- 顶部月份选择；
- 月历；
- 班次图例；
- 本月统计；
- 可切换周列表；
- 支持筛选个人/组织成员，但普通成员默认只看自己。

## 今日班次

在小程序详情基础上增加：导航、添加到系统日历、通知状态、变更时间线。

## 临时改班

显示原班次和可选新班次；生效日期；原因；审批策略说明。提交后进入结果页或状态卡，不要直接返回导致用户不确定是否成功。

## 消息中心

分类：班次提醒、天气提醒、审批/互动、系统通知。支持全部已读、单条已读、按分类筛选和深链跳转。

## 个人统计

- 本月班次天数；
- 预计工时；
- 班次分布环图；
- 每周趋势；
- 改班次数；
- 数据口径说明。

## 我的

账号、工作空间切换、默认地点、班次模板、通知、外观、隐私、设备、帮助与注销。

## 离线体验

- 首页、月历和周视图读取最近缓存；
- 离线状态明确标识同步时间；
- 离线编辑可保存为本地草稿，恢复网络后由用户确认同步；
- 冲突时不能静默覆盖服务端版本。
