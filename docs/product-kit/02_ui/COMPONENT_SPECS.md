# 组件规格

## ShiftBadge 班次标签

属性：`type`、`label`、`shortLabel`、`size`、`status`、`icon`。

- 高度 24/28/32 px；
- 左右内边距 8–12 px；
- 默认浅色背景 + 深色文字；
- 选中态可使用实色背景 + 白字；
- 禁止只展示无文字色块。

## CalendarMonth 月历

- 7 列固定网格；
- 日期点击区域不小于 40×44 px；
- 每格最多直接展示两条班次，更多使用 `+N`；
- 今日使用轮廓或圆形背景；选中日使用品牌色实底；
- 前后月日期降低对比度；
- 支持滑动切月与按钮切月；
- 屏幕阅读器读出完整日期、班次和状态。

## ScheduleSummaryCard 今日班次卡

显示：班次名、状态、时间、地点、天气、主要操作。

- 时间是视觉主信息；
- 跨午夜显示“次日”；
- 无地点时不保留空行；
- 天气区域可独立骨架和失败状态；
- 进行中状态使用绿色，但不要持续闪烁。

## WeatherCard 天气卡

显示：天气现象、当前/区间温度、湿度、风向风力、空气质量、更新时间。

- 数据不完整时按字段降级；
- 异常天气显示警告条；
- 不直接在视图层绑定具体天气供应商字段。

## TimeRangePicker 时间范围

- 支持普通与次日结束；
- 选择器显示日期归属说明；
- 结束早于开始时自动提示“次日”，不可默默计算；
- 提供班次模板快捷选项；
- 支持 5/10/15/30 分钟步进配置。

## SharePosterPreview 分享海报预览

- 预览比例与导出比例一致；
- 导出建议 1080 px 宽；
- 长班次名称需要截断或缩放策略；
- 必须显示班次图例；
- 生成中展示进度，失败提供重试；
- 隐私项在生成前可预览。

## DataTable 管理后台表格

- 表头固定；
- 支持列配置、筛选、排序、分页、批量选择；
- 操作列固定右侧；
- 删除/覆盖操作二次确认；
- 空状态区保留创建入口；
- 加载时使用表格骨架，不让布局跳动。

## ConflictPanel 冲突面板

按严重程度分组：重叠、休息不足、人员缺口、无技能资质、异常天气。

每项显示影响对象、日期时间、原因、建议和是否允许覆盖。覆盖必须要求权限与原因。

## Form 标准

- 标签优先置于输入框上方；
- 必填标记不能只用颜色；
- 错误信息紧邻字段；
- 提交失败后焦点移动到第一个错误字段；
- 弹窗表单最多承载短流程，复杂排班使用独立页面或抽屉。
