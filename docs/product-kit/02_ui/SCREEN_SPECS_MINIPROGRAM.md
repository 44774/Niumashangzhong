# 小程序页面规格

## 我的班表（月历）

### 页面结构

- 顶部品牌色标题栏；
- 月份切换、今天按钮；
- 7 列月历；
- 班次图例；
- 今日排班摘要卡；
- 底部导航。

### 交互

- 点击日期进入排班详情；
- 左右滑动切月；
- 长按日期可快速添加或修改；
- 无数据时日历仍可浏览；
- 切月后仅请求当前可视日期范围及少量前后缓冲。

## 排班详情

- 完整日期与星期；
- 班次大标签；
- 上下班时间、时长、地点、备注；
- 天气卡；
- 临时改班、分享班表按钮。

待审批时需同时显示当前生效排班与申请中的新排班。

## 临时改班

- 原班次只读；
- 班次模板选择；
- 可切换为自定义时间；
- 作用日期默认为当前日；
- 原因/备注；
- 保存或提交审批。

页面底部明确文案：“仅修改当天，不影响其他日期”。若用户主动选择修改循环，必须进入独立确认流程。

## 周视图

按日期列表展示：星期、班次、时间、天气。今日行高亮。休息日仍显示，不显示虚假天气要求。

## 分享班表

- 海报模板；
- 日期范围；
- 隐私开关；
- 实时预览；
- 保存图片、分享好友、朋友圈。

微信分享能力受平台限制时，提供清晰的用户操作引导，不伪造成功状态。

## 设置

上班提醒、提醒时间段、天气推送、班次管理、临时改班记录、分享设置、隐私与注销。
